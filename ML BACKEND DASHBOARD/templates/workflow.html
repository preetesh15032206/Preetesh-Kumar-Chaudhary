System Workflow

END-TO-END PIPELINE ARCHITECTURE
Hardware Sensors
Arduino UNO collects 5 readings and transmits over Serial at 9600 baud.

Format: temp,humid,precip,uv,press
Temp
Sensor: DHT11
Pin: DATA→D4 · VCC 5V

Output: e.g. 31.5°C
Humid
Sensor: DHT11
Pin: DATA→D4 · VCC 5V

Output: e.g. 66.9%
Press
Sensor: BMP180 (I2C)
SDA→A4, SCL→A5 · VCC 3.3V/5V

Expected range: 995-1013 hPa
UV Index
Sensor: Analog UV
Pin OUT→A1 · VCC 5V

0 = night, 3-5 = moderate, 8+ = strong
Rainfall
Sensor: HW-038/HW-103
Pin AO→A0 · VCC 5V

Output: 0% = dry, 100% = fully wet
Data Ingestion
Python layer reads and parses the 9600 baud serial string into individual variables.
Validation Layer
Rejects physically impossible values.
Temp: -40 to 60°C
Humid/Rain: 0-100%
UV: 0-16
Press: 850-1100 hPa
(e.g. 1826 hPa = faulty, rejected)
Smoothing Layer
Applies a moving average to remove sensor noise.

e.g. [30, 31, 29, 32, 30] → smoothed to [30.4, 30.5, 30.3]
Feature Eng
Constructs 8 features for ML: Temperature, Humidity, Precipitation, UV, Pressure, Hour, Day of Week, Month
ML Engine
Ensemble of 4 algorithms.

The best-performing model on historical data is saved as weather_model.pkl
Decision Tree
Splits data via feature thresholds to make predictions. Part of 4-model ensemble.
Grad Boost
Builds sequential trees to correct errors of prior trees for high accuracy.
KNN
Classifies weather by comparing current readings to the nearest historical neighbors.
Random Forest
Averages predictions across many randomized decision trees to prevent overfitting.
Prediction & Scoring
Outputs Sunny/Cloudy/Rainy with confidence % (e.g. Cloudy, 67.9%).

Also hosts separate 2-Hour Forecast Model (forecast_model.pkl).
Live Validation
Cross-references local AI predictions against external live APIs for validation accuracy.
Flask Backend
Flask Backend (app.py)

Serves API endpoints, sensor data, current prediction, 2-Hour forecast, and dashboard communication.
Dashboard
Displays temp, humidity, pressure, UV, rain, current weather, confidence, forecast, and historical charts.
